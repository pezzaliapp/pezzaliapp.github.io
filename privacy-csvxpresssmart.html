Privacy Policy

App: CSVXpressSmart Pezzali per Android e iOS · Aggiornato il 20 agosto 2026

In sintesi: CSVXpressSmart Pezzali non richiede un account, non contiene pubblicità e non utilizza sistemi di tracciamento dell'utente. I file selezionati vengono elaborati localmente sul dispositivo e non vengono inviati a server dello sviluppatore.

1. Titolare del trattamento

Alessandro Pezzali · Sito web: www.alessandropezzali.it

2. Dati raccolti dall'app

CSVXpressSmart Pezzali non richiede registrazione o autenticazione e non raccoglie, memorizza o trasmette a server dello sviluppatore dati personali o dati di utilizzo dell'utente.

In particolare, l'app non raccoglie autonomamente:

  • Nome, cognome, email, numero di telefono o altri dati identificativi
  • Dati di geolocalizzazione
  • Identificatori pubblicitari o identificatori utilizzati per il tracciamento
  • Dati di utilizzo per finalità di analytics o profilazione
  • Contatti, rubrica o calendario
  • Foto, video o audio
  • Dati destinati alla pubblicità personalizzata

3. File selezionati dall'utente

CSVXpressSmart consente all'utente di selezionare e utilizzare file attraverso le funzioni messe a disposizione dal sistema operativo. I file vengono elaborati localmente sul dispositivo.

I contenuti dei file:

  • Non vengono inviati a server dello sviluppatore
  • Non vengono utilizzati per profilazione o pubblicità
  • Non vengono venduti o ceduti a terze parti
  • Vengono utilizzati esclusivamente per le funzioni richieste dall'utente

L'utente mantiene il controllo sui propri file e sulle relative operazioni di apertura, importazione, esportazione e salvataggio.

4. Elaborazione locale

Le principali funzioni di CSVXpressSmart vengono eseguite localmente sul dispositivo.

L'app non necessita di server dello sviluppatore per elaborare i contenuti dei file utilizzati dall'utente.

Alcune funzioni opzionali di condivisione possono tuttavia richiedere una connessione Internet quando l'utente sceglie volontariamente di utilizzare un servizio esterno, ad esempio WhatsApp.

5. Pubblicità, analytics e tracciamento

CSVXpressSmart Pezzali non contiene pubblicità e non integra sistemi destinati al tracciamento, alla profilazione commerciale o all'analisi comportamentale dell'utente.

L'app non utilizza SDK pubblicitari o servizi dello sviluppatore finalizzati alla raccolta di dati personali degli utenti.

6. Servizi di terze parti e condivisione

CSVXpressSmart permette all'utente di esportare o condividere volontariamente report e contenuti generati dall'app.

Quando l'utente sceglie di condividere un contenuto tramite un'applicazione o un servizio esterno, ad esempio WhatsApp, l'operazione viene avviata esclusivamente su richiesta dell'utente.

Dal momento in cui il contenuto viene trasferito al servizio scelto, il relativo trattamento dei dati è soggetto alle condizioni e alla Privacy Policy del servizio esterno utilizzato.

CSVXpressSmart non invia automaticamente file o report a tali servizi.

7. Salvataggio ed esportazione

I report e i file generati dall'app possono essere salvati dall'utente nelle posizioni consentite dal sistema operativo.

La destinazione del file e l'eventuale successiva condivisione sono sotto il controllo dell'utente.

8. Account

CSVXpressSmart Pezzali non richiede la creazione di un account, login, password o registrazione.

Lo sviluppatore non mantiene quindi un archivio remoto di account degli utenti dell'app.

9. Conservazione dei dati

Poiché CSVXpressSmart non invia i contenuti dei file a server dello sviluppatore, lo sviluppatore non conserva copie remote dei documenti elaborati dall'utente.

Gli eventuali dati o file conservati localmente possono essere gestiti o eliminati dall'utente tramite le normali funzioni dell'app e del sistema operativo, oppure rimuovendo l'applicazione.

10. Sicurezza

L'elaborazione locale riduce la necessità di trasferire dati verso infrastrutture esterne.

L'accesso ai file avviene attraverso le funzionalità previste dal sistema operativo Android o iOS e sotto il controllo dell'utente.

11. Diritti dell'utente

CSVXpressSmart non mantiene presso server dello sviluppatore archivi contenenti i file o i dati personali elaborati localmente dall'utente.

Per qualsiasi richiesta o chiarimento relativo alla privacy è comunque possibile contattare lo sviluppatore tramite il sito indicato nella presente policy.

12. Modifiche alla Privacy Policy

Eventuali modifiche a questa Privacy Policy saranno pubblicate su questa pagina indicando la nuova data di aggiornamento.

13. Piattaforme

La presente Privacy Policy si applica alle versioni di CSVXpressSmart Pezzali distribuite per Android e iOS.

14. Contatti

Per domande relative alla privacy di CSVXpressSmart Pezzali è possibile contattare lo sviluppatore tramite: www.alessandropezzali.it
